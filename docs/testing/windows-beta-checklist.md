# Windows beta checklist

What testers try on a real Windows PC before a beta goes to production. These parts were never run on Windows by the
people who built them. Report what fails with the support button ("Send logs").

## Install and update

1. Install from the beta download (beta.pitlanehq.app/dl/beta/). The install folder holds one PitlaneHQ.exe window file
   and the agent, nothing else is left behind.
2. Start Pitlane HQ, close it from the tray, start it again. It opens on the last screen.
3. Turn on Settings → Test builds, then check for updates. A newer beta installs and the app comes back by itself.
4. Uninstall. The "Why did you uninstall" page opens and the install folder is gone.

## Overlays

5. Overlays tab. Each overlay's settings window shows its preview on the left and grows instead of scrolling.
6. Add a column to the relative. The window widens by that column and the text keeps its size.
7. Set one overlay to 10 fps and another to 60 fps. Both keep their own rate in a session.
8. The new spotter overlay. A car alongside lights the bar on its side (amber, red for two cars).
9. Save an overlay set, choose it for Oval under "Open by itself in", join an oval session. That set opens, not the Auto ones.
10. Coach → Practise on a corner. The coach overlay shows only that corner and its time after every pass.

## In development (testers)

11. Watch in replay. After a few laps, press ▶ Replay on a coach corner. iRacing's replay jumps to that corner and plays.
    Try it again from the phone or the web while the PC is in the session.
12. Pedal and wheel check. Drive three laps without pressing the brake past half. Home shows the check.

## Everywhere

13. Home shows "Goals for this session" in a second session on the same car and track, and "Your week".
14. A race summary starts with "Race story".
15. Community → Friends → Invite a friend copies a link. An account made from it follows you and you follow it.
